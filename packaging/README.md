# Packaging

Retroscrappy is pure Python, so a single architecture-independent package
(`_all.deb`, `.noarch.rpm`) serves every Debian, Ubuntu and Fedora release
that ships the dependencies.

## Layout on disk

Both packages install the same files:

| Path | Contents |
|---|---|
| `/opt/retroscrappy/lib/retroscrappy/` | Python package (byte-compiled on install) |
| `/usr/bin/retroscrappy`, `/usr/bin/retroscrappy-gui` | launchers using the system `python3` |
| `/usr/share/applications/io.github.retroboxproject.retroscrappy.desktop` | menu entry |
| `/usr/share/icons/hicolor/*/apps/io.github.retroboxproject.retroscrappy.*` | icon (SVG + PNG sizes rendered at build time) |
| `/usr/share/metainfo/io.github.retroboxproject.retroscrappy.metainfo.xml` | AppStream data |

The code lives in `/opt` rather than in the distribution's Python path
because Fedora's `site-packages` path includes the Python version; with
`/opt` one `.rpm` keeps working across Fedora upgrades.

## Dependencies

| | Debian / Ubuntu | Fedora |
|---|---|---|
| Required | `python3 (>= 3.11)`, `python3-requests`, `python3-pyside6.qtcore`, `python3-pyside6.qtgui`, `python3-pyside6.qtwidgets`, `python3-pyside6.qtsvg` | `python3 >= 3.11`, `python3-requests`, `python3-pyside6` |
| Recommended | `qt6-wayland` | `qt6-qtwayland` |

PySide6 is packaged in Debian 13 (trixie) and later, Ubuntu after 24.04 and
current Fedora. On older releases, or on immutable systems, use
[`install.sh`](../install.sh) instead.

## Building locally

```bash
packaging/build-deb.sh   # needs dpkg-deb  → dist/retroscrappy_<ver>-1_all.deb
packaging/build-rpm.sh   # needs rpmbuild  → dist/retroscrappy-<ver>-1.noarch.rpm
```

`PACKAGE_RELEASE` (default `1`) and `PACKAGE_MAINTAINER` can be set in the
environment. The version always comes from `src/retroscrappy/__init__.py`.

## Releases (GitHub Actions)

`.github/workflows/packages.yml` runs only when a tag `vX.Y.Z` is pushed;
ordinary commits do not trigger it. It then:

1. checks that the tag points at a commit of `main` and matches
   `__version__`;
2. runs pylint, pytest and shellcheck;
3. builds the `.deb` and `.rpm`;
4. installs them with `apt` in `debian:trixie` (and, informatively,
   `ubuntu:rolling`) and with `dnf` in `fedora:latest`, opens the main
   window off-screen and uninstalls them again;
5. publishes a GitHub release with both packages and a `SHA256SUMS` file.

The maintainer field can be changed with the repository variable
`PACKAGE_MAINTAINER`.

## Icon

The only icon file in the repository is the SVG
`src/retroscrappy/data/icons/io.github.retroboxproject.retroscrappy.svg`,
organised in named Inkscape layers (background, sun, grid, cartridge,
label). Edit it directly; nothing has to be regenerated by hand:

- the package build installs it as the scalable icon and renders the PNG
  sizes (16–512 px) with `rsvg-convert` (`librsvg2-bin` on Debian,
  `librsvg2-tools` on Fedora);
- `install.sh` does the same when `rsvg-convert` is available;
- the application renders it with QtSvg for its window icon when the theme
  icon is not installed.

Keep it renderable by Qt's SVG engine, which KDE Plasma uses for icons:
avoid clip paths and masks, and prefer plain paths and gradients.

## PyPI

`pyproject.toml` is complete (`python -m build` gives an sdist and a wheel);
the wheel includes the platform table and the SVG icon.
